# Yi-Sun-sin Idle Game (이순신 키우기)
Unity 기반 2D Merge 방치형 모바일 게임입니다.  

기존 방치형 성장 구조를 참고하여 팀 프로젝트로 제작하였습니다.

## 프로젝트 개요
- 개발 환경 : Unity 2D
- 사용 언어 : C#
- 개발 기간 : 2023년 01월 ~ 2023년 05월
- 개발 인원 : 3인 (팀 프로젝트)
- 담당 역할 : 클라이언트 개발
- 플랫폼 : Android (Mobile)

## 주요 기능
- 캐릭터 합성 및 성장 시스템 (Merge) — 같은 캐릭터를 합성해 상위 캐릭터로 성장
- 미니게임 / 보스 콘텐츠 — 추가 재화 획득 및 성장 콘텐츠
- JSON 기반 게임 데이터 저장 및 복원 — 앱 종료 후 재실행 시 이전 상태 유지

## 기술적 고민
### 1. JSON 기반 캐릭터 배치 데이터 저장 및 복원 시스템
- 캐릭터의 생성 여부, 위치, 레벨 정보를 저장하기 위해 JSON 기반 저장 구조를 구현했습니다.
- 게임 종료 후 다시 실행해도 배치된 캐릭터 상태가 유지되도록 저장 데이터와 게임 오브젝트 생성 로직을 연결했습니다.

## 회고
기존 방치형 게임 구조를 참고해 팀 프로젝트로 개발하면서, 캐릭터 성장과 저장 데이터를 하나의 흐름으로 연결하는 경험을 했습니다.

특히 캐릭터의 생성 여부, 위치, 레벨 정보를 JSON으로 저장하고,  
앱 재실행 시 저장 데이터를 기준으로 오브젝트를 복원하는 과정에서 저장 데이터와 실제 게임 오브젝트 상태를 일치시키는 것이 중요하다는 점을 배웠습니다.

이번 프로젝트를 통해 기능 구현 전에 데이터 구조와 오브젝트 생성 흐름을 먼저 정리하는 것이 유지보수와 기능 확장에 중요하다는 점을 경험했습니다.
