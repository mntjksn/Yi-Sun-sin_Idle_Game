# Yi-Sun-sin Idle Game (이순신 키우기)

Unity 기반으로 개발한 2D Merge 방치형 모바일 게임입니다.  
팀 프로젝트로 진행했으며, 전투 성장 구조와 캐릭터 강화 시스템을 중심으로 개발했습니다.

---

## 🎮 프로젝트 개요
- 장르: 2D Merge / 방치형 성장 게임  
- 개발 인원: 3인 팀 프로젝트  
- 담당 역할: 전반적인 기획, 클라이언트 프로그래머  
- 개발 도구: Unity, C#  

---

## 🛠 기술 스택
- Engine: Unity  
- Language: C#  
- Data: JSON  
- Platform: Android
  
---

## 🧑‍💻 담당 역할
- 캐릭터 성장 및 강화 시스템 구현
- 골드 획득 및 보상 로직 개발
- UI 연동 및 데이터 저장(JSON) 처리
- 버그 수정 및 기능 개선

- 골드 및 보상 획득 로직

- 기본 UI 연동
